# Copyright-safe learning resources

Video resources store only a canonical YouTube embed URL and educational metadata (title, subject and tags). The platform never downloads, proxies, mirrors, transcodes, or claims ownership of third-party video.

Students can bookmark resources; tutors can assign them. Reports immediately remove a resource's external links and create an open moderation item. The dead-link worker also removes unreachable links. Resource records remain so moderators have context.

Tutor-created materials are private uploads only: the tutor must affirm they hold the required rights, bytes are checked using the shared D7 signature/size policy, and uploads remain quarantined for review. Video MIME types are rejected; tutors use a YouTube link for video instead.
